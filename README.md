Java Quest 🎮🐏

Java Quest is an educational web-based game designed to teach Java programming logic and loops through adaptive gameplay, quizzes, XP progression, badges, and interactive coding challenges.

Built with:
  HTML
  CSS
  JavaScript

Inspired by the Winston-Salem State University (WSSU) Rams theme.

Features:
  Adaptive Learning System
  Pre-quiz evaluates player knowledge
  Recommends:
  Difficulty level
  Hint level
  Prevents content from being too easy or too difficult
  Java Loop Practice

Students practice:
  for loops
  while loops
  nested loops
  loop conditions
  loop updates
  logic and iteration
  Output-Based Validation

The game evaluates:
  loop structure
  loop logic
  generated output
Instead of requiring exact syntax matches.

This allows multiple valid solutions such as:
  i <= 5
  i < 6
  for loops or while loops (when allowed)
  
Gamification
Players earn:
  XP
  points
  badges

Rewards are based on:
  correctness
  first-try success
  reduced hint usage
  Mastery-Based Progression
  Easy
  Reach 100 XP
  Medium & Hard
  Reach 100 XP
  AND complete all questions at least once
  Post-Quiz & Improvement Tracking

The game compares:
  pre-quiz performance
  post-quiz performance

Using percentage-based improvement tracking.
